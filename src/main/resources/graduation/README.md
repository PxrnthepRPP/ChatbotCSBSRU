# ใบตรวจสอบจบ (Graduation Audit) — 1 ไฟล์ต่อนักศึกษา 1 คน

หน้า "ตรวจสอบจบ" และแชทบอทอ่านข้อมูลชุดเดียวกันจากตาราง `graduation_audits`
ระบบ**คำนวณเอง**ว่าแต่ละหมวดผ่าน/ไม่ผ่าน, หน่วยกิตรวม, GPA, รายการที่ยังขาด
ไฟล์จึงเก็บแค่ "ข้อมูลดิบ" (โครงหลักสูตร + รายวิชาที่เรียน + เกรด)

## วิธีเพิ่มข้อมูลนักศึกษาคนใหม่

**วิธีที่ 1 — ผ่านหน้าเว็บ (ไม่ต้อง restart)**
1. ล็อกอิน `admin` → เมนู "จัดการนักศึกษา"
2. กด **⬇ ใบตรวจจบ** ที่แถวของนักศึกษา ถ้ายังไม่มี ระบบจะให้ใบของ 6621100042 มาเป็นแม่แบบ (`<รหัส>-template.json`)
3. แก้ไฟล์ (ดูรูปแบบด้านล่าง) แล้วกด **⬆ อัปโหลด** ที่แถวเดียวกัน → ระบบตรวจไฟล์ คำนวณ และแสดงผลสรุปทันที

**วิธีที่ 2 — วางไฟล์ในโฟลเดอร์นี้**
1. ตั้งชื่อไฟล์เป็น `<รหัสนักศึกษา>.json` เช่น `6721100099.json`
2. build/restart backend → `DataSeeder` โหลดให้อัตโนมัติ (เฉพาะนักศึกษาที่มีในระบบและยังไม่มีใบตรวจจบ — ใบที่อัปโหลดผ่านเว็บจะไม่ถูกทับ)

## รูปแบบไฟล์

```jsonc
{
  "curriculum": "วท.บ. วิทยาการคอมพิวเตอร์ (หลักสูตรปรับปรุง)",
  "minGpa": 2.0,                       // เกณฑ์ GPA ขั้นต่ำ
  "sections": [                         // หมวดใหญ่ 1., 2., 3., 4.
    {
      "id": "sec-1",
      "title": "1. หมวดวิชาศึกษาทั่วไป",
      "subsections": [                  // หมวดย่อย (มี subsections ซ้อนได้ เช่น 2.2 → 2.2.1, 2.2.2)
        {
          "id": "sec-1-1",
          "title": "1.1 วิชาศึกษาทั่วไปบังคับ",
          "minCr": 20,                  // หน่วยกิตขั้นต่ำของหมวดนี้ (ไม่ใส่ = รวมจากกลุ่มย่อย)
          "groups": [                   // กลุ่มวิชา
            {
              "code": "1.1.1",
              "title": "กลุ่มที่ 1 ศาสตร์พระราชาและวิถีแห่งสังคม",
              "minCr": 3,
              "courses": [
                {
                  "code": "GE01101",
                  "name": "ศาสตร์พระราชาสู่การพัฒนาท้องถิ่น",
                  "credits": "3(3-0-6)",
                  "ca": 3,              // หน่วยกิตที่ได้ (null = ยังไม่ได้เรียน/ยังไม่ผ่าน)
                  "pt": 12.0,           // แต้ม = หน่วยกิต × ค่าเกรด (A=4, B+=3.5, B=3, C+=2.5, C=2, D+=1.5, D=1)
                  "avg": "4.00",
                  "max": "4.00",
                  "terms": { "2": "A 2/66" }   // เทอมที่ (1–8) → "เกรด ภาค/ปี", "-- 1/69" = กำลังเรียน รอผล
                }
              ]
            }
          ]
        }
      ]
    }
  ]
}
```

### กติกาพิเศษของหมวด (`"rule"`)
| rule | ใช้กับ | ความหมาย |
|---|---|---|
| (ไม่ใส่) | ทั่วไป | รวมหน่วยกิตจากกลุ่ม ผ่านเมื่อได้ ≥ `minCr` |
| `ONE_PER_GROUP` + `"groupsRequired": 3` | 1.2 ศึกษาทั่วไปเลือก | ต้องเรียนกลุ่มละ 1 วิชา ให้ครบ 3 กลุ่ม (เรียนเกิน 1 วิชาในกลุ่มเดียว = ไม่ผ่าน) |
| `CHOOSE_ONE` | 2.3 พื้นฐานวิชาชีพ | เลือกแผนใดแผนหนึ่ง (ฝึกประสบการณ์ หรือ สหกิจ) นับแผนที่ได้มากสุด |
| `REQUIREMENT` (ใส่ที่ group) | 4. กลุ่มทักษะ | ไม่นับหน่วยกิต ต้องมี `"passed": true` ทุกรายวิชา (CEFR, DL) |

### ไม่ต้องใส่ (ระบบคำนวณเอง และจะลบทิ้งถ้าใส่มา)
`status`, `passCr`, `gpa`, `summary`, `groupsPassed`, `violation`
