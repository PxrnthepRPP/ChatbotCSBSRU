## 📋 1. สิ่งที่ต้องติดตั้งล่วงหน้า (Prerequisites)

ก่อนเริ่มใช้งานระบบ กรุณาตรวจสอบว่าเครื่องของท่านติดตั้งซอฟต์แวร์ดังต่อไปนี้แล้ว:
1. **Docker Desktop** (สำหรับรัน PostgreSQL 16 + pgvector บน Port 5432)
2. **Java 21 LTS** (เช่น Microsoft JDK 21 หรือ OpenJDK 21)
3. **Apache Maven 3.9+** (ไม่บังคับ — ใช้ Maven Wrapper `mvnw.cmd` / `./mvnw` ในโฟลเดอร์โปรเจกต์ได้เลย ระบบจะดาวน์โหลด Maven 3.9.9 ให้อัตโนมัติ)
4. **XAMPP / Apache Web Server** (สำหรับโฮสต์หน้าเว็บ Frontend บน Port 80)
5. **Google Gemini API Key** (รับฟรีได้ที่ [Google AI Studio](https://aistudio.google.com/apikey))
6. **Web Browser รุ่นล่าสุด** (Google Chrome, Microsoft Edge, Firefox, Safari)

### ขั้นตอนที่ 1: ตั้งค่าตัวแปรสภาพแวดล้อม (.env)
1. คัดลอกไฟล์แม่แบบ `.env.example` ไปเป็น `.env`:
   ```powershell
   copy .env.example .env
   ```
2. เปิดไฟล์ `.env` ด้วย Text Editor แล้วแก้ไขค่า `GEMINI_API_KEY` ด้วย API Key ของคุณ:
   ```env
   GEMINI_API_KEY=AIzaSy...your-actual-api-key...
   ```
   > 💡 **หมายเหตุ:** ไฟล์ `.env` ได้ถูกเพิ่มลงใน `.gitignore` เรียบร้อยแล้ว จึงปลอดภัยไม่ถูกอัปโหลดขึ้น Git Repository

### ขั้นตอนที่ 2: สตาร์ทฐานข้อมูล PostgreSQL 16 + pgvector (Port 5432)
1. เปิดโปรแกรม **Docker Desktop** บนคอมพิวเตอร์ของคุณ และรอจนกระทั่งไอคอนด้านล่างซ้ายขึ้นสถานะ **Engine running (สีเขียว)**
2. เปิด PowerShell หรือ Terminal เข้าไปที่โฟลเดอร์โปรเจกต์:
   ```powershell
   cd c:\xampp\htdocs\ChatbotCSBSRU
   ```
3. สตาร์ทคอนเทนเนอร์ฐานข้อมูล:
   ```powershell
   docker-compose up -d
   ```
4. ตรวจสอบว่าคอนเทนเนอร์ `bsru_vector_db` ทำงานปกติ:
   ```powershell
   docker ps
   ```

### ขั้นตอนที่ 3: รันระบบหลังบ้าน Spring Boot Backend (Port 8080)

**วิธีที่ 1 — ใช้ Quick Start Script (แนะนำที่สุด):**
- **PowerShell:**
  ```powershell
  .\start-backend.ps1
  ```
- **Windows Command Prompt / ดับเบิลคลิก:**  
  ดับเบิลคลิกที่ไฟล์ `start-backend.bat` ได้โดยตรง  
  *(สคริปต์จะอ่านค่าจากไฟล์ `.env` และตั้งค่า Environment Variables ให้โดยอัตโนมัติ)*

**วิธีที่ 2 — รันด้วย Maven Command เอง (Manual):**
```powershell
$env:GEMINI_API_KEY = "your-gemini-api-key"
mvn spring-boot:run
```
*(หรือหากใช้ Maven Wrapper: `.\mvnw.cmd spring-boot:run`)*

เมื่อระบบสตาร์ทสำเร็จ จะแสดงข้อความ:
```text
Started BsruStudentPortalApplication in X.XXX seconds
Tomcat started on port 8080 (http) with context path '/'
```

> 🔍 **ตรวจสอบสถานะ Backend:**  
> เปิดเบราว์เซอร์ไปที่: 👉 **`http://localhost:8080/api/health`**  
> จะได้รับ JSON ตอบกลับสถานะ `UP` พร้อมจำนวนข้อมูลในฐานข้อมูล
>
> 💡 **วิธีหยุดการทำงาน Backend / ปิดสคริปต์ใน Terminal:**  
> คลิกที่หน้าต่าง Terminal ที่กำลังรันอยู่ แล้วกด **`Ctrl + C`** (หากระบบถาม `Terminate batch job (Y/N)?` ให้พิมพ์ **`Y`** แล้วกด `Enter`) หรือคลิกปุ่มถังขยะ **Kill Terminal** ใน VS Code

### ขั้นตอนที่ 4: เปิดใช้งานหน้าบ้าน Frontend (Port 80 / XAMPP)

   👉 **`http://localhost/ChatbotCSBSRU/`**

> ⚠️ **คำเตือนสำคัญมาก:**  
> **ห้าม** ดับเบิลคลิกเปิดไฟล์ `index.html` ผ่าน `file:///` โดยตรง เพราะระบบใช้ JavaScript ES6 Modules (`import`/`export`) ซึ่งเบราว์เซอร์จะบล็อกด้วยนโยบายความปลอดภัย CORS — **ต้องเข้าผ่าน `http://localhost/ChatbotCSBSRU/` เท่านั้น**

### ขั้นตอนที่ 5: วิธีปิดระบบและหยุดการทำงาน (Shutdown & Stop Environment)

เมื่อต้องการปิดระบบหรือเลิกใช้งานแต่ละส่วน สามารถทำได้ดังนี้:

| ส่วนที่ต้องการปิด | วิธีการปิด / คำสั่ง | รายละเอียดเพิ่มเติม |
|---|---|---|
| 🛑 **Spring Boot Backend** | กด **`Ctrl + C`** ใน Terminal | หากขึ้นถาม `Terminate batch job (Y/N)?` ให้พิมพ์ `Y` แล้วกด `Enter` หรือกดปุ่มถังขยะ **Kill Terminal** ที่มุมขวาบนของ Terminal |
| 🗄️ **ฐานข้อมูล Docker (PostgreSQL)** | `docker-compose down` | รันคำสั่งนี้ใน PowerShell เมื่อต้องการปิดและหยุด Container ฐานข้อมูล |
| 🧹 **ตัวแปรสภาพแวดล้อม (.env)** | ปิดหน้าต่าง Terminal | ค่าตัวแปรสภาพแวดล้อมจาก `.env` ผูกอยู่เฉพาะ Process ของ Terminal นั้น เมื่อปิดหน้าต่าง Terminal ตัวแปรจะถูกล้างทิ้งอัตโนมัติ (หรือใช้คำสั่ง `Remove-Item env:GEMINI_API_KEY`) |
| 🌐 **Frontend (Apache)** | คลิก **Stop** ใน XAMPP | เปิด **XAMPP Control Panel** แล้วคลิกปุ่ม **Stop** ที่โมดูล **Apache** |

### 4.4 การนำเข้าเอกสารความรู้ใหม่เข้าสู่ AI Vector Database (Admin Ingestion)
ผู้ดูแลระบบสามารถส่งเอกสาร PDF / ข้อความคู่มือหลักสูตรใหม่เข้าสู่ระบบ RAG ได้ผ่าน REST API:
```powershell
# 1. เข้าสู่ระบบเพื่อรับ JWT Token
$login = Invoke-RestMethod -Uri "http://localhost:8080/api/auth/login" -Method Post -Body (@{ username = "admin"; password = "password" } | ConvertTo-Json) -ContentType "application/json; charset=utf-8";

# 2. ส่งเอกสารความรู้เข้าสู่ระบบ
$doc = @{
    content = "ข้อบังคับมหาวิทยาลัยราชภัฏบ้านสมเด็จเจ้าพระยา: นักศึกษาที่ประสงค์จะขอเปิดรายวิชาเรียนกรณีพิเศษ ต้องมีจำนวนนักศึกษาลงชื่อไม่น้อยกว่า 10 คน และได้รับความเห็นชอบจากอาจารย์ผู้สอนและหัวหน้าสาขาวิชา";
    source = "bsru_special_course_regulation.pdf";
} | ConvertTo-Json;

Invoke-RestMethod -Uri "http://localhost:8080/api/admin/knowledge/ingest" -Method Post -Headers @{ "Authorization" = "Bearer " + $login.token } -Body ([System.Text.Encoding]::UTF8.GetBytes($doc)) -ContentType "application/json; charset=utf-8";
```

### 4.5 การจัดเก็บและอัปเดตสายอาชีพบัณฑิต (Graduate Career Tracking)

ระบบออกแบบการจัดเก็บข้อมูลเส้นทางอาชีพของบัณฑิตและนักศึกษาชั้นปีสุดท้ายอย่างยืดหยุ่น โดยรองรับ 2 ช่องทางหลัก:

#### 1. ฝั่งนักศึกษาอัปเดตข้อมูลด้วยตนเอง (Self-Service)
นักศึกษาสามารถเข้าถึงและอัปเดตข้อมูลสายอาชีพได้จาก 2 หน้าเมนู:
- **หน้า "ตรวจสอบจบ (Graduation Audit)":** มีแถบแจ้งเตือนพิเศษ (Career Callout Banner) พร้อมปุ่ม **"อัปเดตข้อมูลสายอาชีพ / ที่ทำงาน"**
- **หน้า "ประวัตินักศึกษา (Bibliography)":** มีกล่องการ์ดสรุปสายอาชีพปัจจุบัน พร้อมปุ่ม **"แก้ไขสายอาชีพ"**
- **ข้อมูลที่กรอกและเลือกได้:**
  1. **สถานะการทำงาน (Employment Status):** มีงานทำแล้ว (ตรงสาย IT), มีงานทำแล้ว (งานทั่วไป), ศึกษาต่อระดับปริญญาโท, กำลังศึกษาต่อ/อบรมทักษะ, กำลังหางาน (Open to Work), ประกอบธุรกิจส่วนตัว/ฟรีแลนซ์
  2. **สายอาชีพเป้าหมาย/ปัจจุบัน (Career Path):** เลือกจาก 18+ สายอาชีพมาตรฐาน เช่น *Software Engineer, Full-Stack Developer, AI/Machine Learning Engineer, Data Scientist, Cloud & DevOps, Cybersecurity Specialist* ฯลฯ
  3. **สถานที่ทำงาน / บริษัท (Company / Organization):** ระบุชื่อบริษัท องค์กร หรือหน่วยงาน
  4. **ช่วงเงินเดือน (Salary Range):** ต่ำกว่า 20,000 บาท, 20,000 - 30,000 บาท, 30,001 - 45,000 บาท, 45,001 - 70,000 บาท, มากกว่า 70,000 บาท
- เมื่อกด **"บันทึกข้อมูลสายอาชีพ"** ข้อมูลจะถูกบันทึกผ่าน API `PATCH /api/students/{id}/career` และซิงค์ลงฐานข้อมูล PostgreSQL ทันที

#### 2. ฝั่งผู้ดูแลระบบจัดการข้อมูลสายอาชีพ (Admin Management)
- เข้าสู่ระบบด้วยบทบาท Admin -> เมนู **"จัดการข้อมูลนักศึกษา" (Manage Students)**
- คลิกปุ่ม **"แก้ไข" (Edit)** ที่แถวนักศึกษาที่ต้องการ
- ใน Modal แก้ไขข้อมูลจะมีดรอปดาวน์ **สายอาชีพ (Career Path)**, **สถานะการทำงาน**, **ชื่อบริษัท**, และ **ช่วงเงินเดือน**
- เมื่อกด **"บันทึกข้อมูล"** แดชบอร์ดสถิติสายอาชีพด้านบน (Career Distribution Bar / Stats) จะถูกคำนวณและอัปเดตกราฟสัดส่วนทันทีแบบ Real-time

#### 3. สอบถามสถิติสายอาชีพผ่าน BSRU AI Chatbot
- ผู้ใช้งานสามารถคลิกชิป Quick Prompt **"💼 สถิติสายอาชีพบัณฑิต"** ในหน้าต่างแชทบอท
- หรือพิมพ์ถาม เช่น *"สถิติสายอาชีพบัณฑิต CS ล่าสุด"*, *"บัณฑิตทำงานตำแหน่งอะไรกันมากที่สุด"* AI Chatbot จะดึงข้อมูลสถิติมาสรุปให้อย่างแม่นยำ

### 4.6 การวิเคราะห์ข้อมูลหลายปีการศึกษา และระบบแบ่งหน้าตาราง (Multi-Year Range Filter & Table Pagination)

เพื่อรองรับฐานข้อมูลนักศึกษาและคำร้องที่มีประวัติสะสมหลายปีการศึกษา ระบบได้เพิ่มเครื่องมือวิเคราะห์และบริหารจัดการข้อมูลขนาดใหญ่:

#### 1. ตัวกรองช่วงปี Preset Range Filter (Admin Dashboard, Manage Students, Manage Petitions)
- **ดรอปดาวน์เลือกช่วงรุ่น:**
  - **ทุกรุ่น / ทุกปีการศึกษา (All Batches):** แสดงภาพรวมทั้งหมดของระบบ
  - **⏱️ 4 ปีล่าสุด:** กรองเฉพาะ 4 รุ่นปีการศึกษาล่าสุด เหมาะสำหรับการประเมินรอบหลักสูตร 4 ปี
  - **เลือกแยกทีละรุ่น:** เลือกรุ่นที่ต้องการเพื่อเจาะลึกเฉพาะรุ่น
  - **🎛️ Multi-Select Chips (เฉพาะในแดชบอร์ด):** สามารถคลิกเลือกหรือสลับหลายรุ่นที่ต้องการเปรียบเทียบได้อย่างอิสระ

#### 2. แผนภูมิวิเคราะห์เปรียบเทียบข้ามรุ่น (Year-over-Year Analytics)
เมื่อเลือกดูแบบหลายรุ่น ระบบจะแสดงส่วนวิเคราะห์พิเศษโดยอัตโนมัติ:
- **📈 GPA Trend by Batch:** กราฟเส้นแนวโน้มผลการเรียนเฉลี่ย (GPA) ตามแต่ละรุ่น
- **📊 Status Breakdown by Batch:** กราฟแท่งเปรียบเทียบสัดส่วนสถานะการศึกษา (กำลังศึกษา, จบการศึกษา, พักการศึกษา, พ้นสภาพ)
- **💼 Career Shift Matrix:** ตารางวิเคราะห์การกระจายตัวและการเปลี่ยนแปลงของสายอาชีพบัณฑิตข้ามรุ่น พร้อมตัวชี้วัดทิศทางเทรนด์ (📈, 📉, 🚀)

#### 3. ระบบแบ่งหน้าตารางประสิทธิภาพสูง (Responsive Table Pagination)
ในหน้า **"จัดการข้อมูลนักศึกษา"** และ **"รายการคำร้องวิชาการ"**:
- **ข้อมูลสรุปแถว:** แสดงแถบสถานะระบุ *"แสดงรายการที่ X - Y จากทั้งหมด Z คน/รายการ"*
- **ตัวเลือกจำนวนรายการต่อหน้า (Page Size Selector):** เลือกแสดงได้ 10, 15, 25, 50 แถวต่อหน้า (สำหรับนักศึกษา) หรือ 5, 10, 20 แถวต่อหน้า (สำหรับคำร้อง)
- **ปุ่มเปลี่ยนหน้า:** ปุ่ม **`◀ ก่อนหน้า`**, เลขหน้า (1, 2, 3...) พร้อมจุดไข่ปลา `…` และปุ่ม **`ถัดไป ▶`**
- ระบบออกแบบให้ลื่นไหล (Smooth Transition) ไม่กระตุกแม้มีข้อมูลนักศึกษาหลายร้อยคน

## 🔧 5. การแก้ไขปัญหาที่พบบ่อย (Troubleshooting)

| ปัญหาที่พบ | สาเหตุที่เป็นไปได้ | วิธีแก้ไข |
|---|---|---|
| **หน้าเว็บขาว / JavaScript ไม่ทำงาน** | เปิดไฟล์ผ่าน `file:///c:/.../index.html` โดยตรง | ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ Apache: **`http://localhost/ChatbotCSBSRU/`** เท่านั้น |
| **`failed to connect to docker API`** | ยังไม่ได้เปิดโปรแกรม Docker Desktop | เปิดโปรแกรม **Docker Desktop** และรอให้ Engine แสดงสีเขียว (Running) ก่อนรัน `docker-compose up -d` |
| **`Connection to localhost:5432 refused`** | คอนเทนเนอร์ PostgreSQL ยังไม่เริ่มทำงาน | รันคำสั่ง `docker start bsru_vector_db` หรือ `docker-compose up -d` |
| **`Port 8080 is already in use`** | มีโปรเซส Spring Boot เดิมค้างอยู่ | รันคำสั่งปิดโปรเซสใน PowerShell: <br>`Get-Process -Id (Get-NetTCPConnection -LocalPort 8080).OwningProcess | Stop-Process -Force` |
| **เข้าหน้าเว็บไม่ได้ (404 Not Found)** | ยังไม่ได้ Start Apache ใน XAMPP หรือ Path โฟลเดอร์ไม่ถูกต้อง | ตรวจสอบว่าโปรเจกต์อยู่ที่ `c:\xampp\htdocs\ChatbotCSBSRU` และเปิดโมดูล Apache ใน XAMPP Control Panel |
| **Chatbot ตอบคำตอบพื้นฐาน (Fallback Mode)** | ยังไม่ได้ใส่ `GEMINI_API_KEY` ใน `.env` หรือ Backend ไม่ได้รัน | คัดลอก `.env.example` ไปเป็น `.env` ใส่ API Key จริง แล้วรัน `.\start-backend.ps1` |
| **เข้าสู่ระบบไม่ได้ (Login Error)** | URL ใน `js/api.js` ไม่ตรงกับ Port หรือ Backend ดับ | ตรวจสอบว่า Backend รันบนพอร์ต 8080 หรือหากทดสอบแบบออฟไลน์ ระบบจะ fallback อัตโนมัติ |
